APOLINA FOR BODY — mobile-first website v2

Запуск локально:
1. Распакуйте архив.
2. Откройте index.html в браузере. Для PWA/service worker лучше разместить папку на HTTPS-хостинге.

Что работает:
- адаптивная версия для Android / iPhone / desktop;
- мобильное меню;
- фильтрация каталога;
- быстрый просмотр товара;
- кнопки покупки на Wildberries;
- у Lavender стоит прямая карточка WB: 893446402;
- у остальных товаров стоят поисковые ссылки Wildberries по точному названию, пока нет их артикулов;
- manifest + service worker для добавления сайта на главный экран телефона.

Для финальной версии:
- заменить поисковые ссылки WB на прямые ссылки товаров, когда будут известны артикулы;
- при желании добавить домен, аналитику и метрики переходов на WB.
