APOLINA — комплект изображений

Основные изображения, которые использует сайт, лежат прямо в папке assets/.
Оригинальные загруженные фотографии дополнительно сохранены в assets/originals/.

Для GitHub Pages загрузите в корень репозитория:
index.html
styles.css
app.js
manifest.webmanifest
sw.js
папку assets целиком

Важно: папку assets нельзя пропускать — иначе сайт откроется без фотографий.
